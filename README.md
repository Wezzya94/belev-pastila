# Белёвская мануфактура: «Слой за слоем»

Полноценный статический сайт для оценки нового дизайна заказчиком. Каталог, фотографии, контакты и адреса собраны из публичных материалов [pastila1881.com](https://pastila1881.com/). Действующий официальный сайт производителя остаётся по исходному адресу.

## Что работает

- Сразу после первого экрана расположен заметный блок трёх функций: «Под упаковкой», «Дегустационная полка» и «Где купить». Он ведёт к просмотру среза, сравнению продуктов и поиску магазина.
- Каталог всех опубликованных товаров: поиск, фильтры сладостей, добавленного сахара и размера упаковки, отдельные страницы с составом и фотографиями.
- «Под упаковкой»: переключение упаковки и реальной фотографии вида пастилы. Подпись объясняет, где снимок относится к виду продукции, а не к конкретному вкусу.
- «Дегустационная полка»: сравнение двух или трёх товаров, удаление, ограничение размера полки, сохранение выбора в браузере.
- «Где купить»: фильтры города и адреса, ссылки на карты и магазины. Наличие конкретного товара требует уточнения у продавца.
- Страницы мануфактуры, сотрудничества и контактов. Письмо открывается в почтовой программе; ложного уведомления об отправке нет.
- Мобильная версия, клавиатурное управление, видимый фокус, поддержка уменьшения анимации, локальные шрифты и изображения.

На сайте нет приёма оплаты, корзины, серверной формы или заявления о наличии товара. Эти функции не были подтверждены исходным сайтом и не нужны для текущего сценария «выбрать → найти магазин».

## Оформление и движение

- Тематический загрузчик «Слой за слоем» служит декоративным вступлением примерно на две секунды: слои собираются внутри яблока. Длительность не зависит от реальной скорости загрузки ресурсов; процентов и сообщений о готовности страницы нет.
- Крупное яблоко заменяет курсор при управлении мышью и оставляет короткий ограниченный след. Над ссылками и кнопками его вид меняется. На сенсорном экране и в полях ввода остаётся обычный указатель.
- Светлая и тёмная темы переключаются кнопкой в шапке. Выбор сохраняется в браузере и применяется при следующем открытии; если сохранение запрещено, переключение работает в текущей странице.
- Заголовки, фотографии, карточки, адреса и другие блоки появляются разными способами: через раскрытие, смещение, лёгкий поворот и изменение прозрачности. Все движения двумерные, доступны на компьютере и телефоне. При фильтрации и клавиатурном фокусе содержимое сразу остаётся читаемым.
- Фон дополняют яблочные контуры и линии слоёв пастилы. Мягкие тени, подсветка фокуса и отклик подписей, карточек и кнопок при наведении поддерживают взаимодействие.

При системной настройке уменьшения движения (`prefers-reduced-motion: reduce`) загрузчик, яблочный курсор и появления отключаются. Содержимое видно по умолчанию, в том числе без JavaScript; оформление не является условием доступа к каталогу.

## Обновление и сопровождение

Данные находятся в `content/`. `products.json` содержит товары, `stores.json` — адреса, `brand.json` — реквизиты и историю, `assets.json` — соответствие исходных фотографий локальным файлам. Не редактируйте собранные страницы вручную: обновите источник данных и пересоберите сайт.

Нужен Node.js 22 или новее. Зависимостей сторонних пакетов нет.

```sh
npm ci
npm test
npm run build
npm run lint
npm run dev
```

Локальный адрес по умолчанию: `http://127.0.0.1:4173/`. Порт можно изменить переменной `PORT`.

`src/` содержит интерфейс и поведение, `scripts/build.mjs` собирает все страницы в `docs/`. Для публикации на GitHub Pages используется ветка `main` и каталог `/docs`. Локальные ресурсы и ссылки относительные, поэтому сайт работает в подпапке репозитория. Сервер разработки вычисляет пути от своего файла и не зависит от текущего каталога терминала.

`SOURCES.md` описывает проверенные источники и ограничения сведений. Все неподтверждённые составы отмечены явно; неизвестное значение сахара не попадает в фильтр «Без добавления сахара».

## Изображения и права

Фотографии и знак принадлежат правообладателям исходного сайта. Эта версия подготовлена для оценки дизайна; права и актуальность материалов необходимо согласовать с заказчиком перед эксплуатацией как его официальный сайт. Изображение на главной очищено от старого фона с помощью ImageGen и используется как обзорная иллюстрация пастилы, не как доказательство состава конкретного товара.

Vollkorn и Golos Text распространяются по SIL Open Font License; тексты лицензий находятся рядом со шрифтами.

## Приёмка

`npm test` проверяет пользовательские правила фильтрации и сравнения. `npm run lint` проверяет исходные данные, локальные пути, синтаксис JavaScript и наличие ресурсов всех собранных страниц. Браузерная проверка и независимое ревью описаны в `REVIEW.md`. Последние изменения загрузчика, курсора, подписей и блока трёх функций ещё находятся в работе и требуют отдельной проверки: прежние результаты не подтверждают эту версию. Репозиторий GitHub пока не создан, публикация новой версии не выполнена.
